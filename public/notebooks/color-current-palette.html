Simulation boundary¶

Colorspacious simulates an observer by converting from the CVD space to sRGB display colors. Clipping into sRGB is a display approximation. Simulation does not replace testing with readers. WCAG thresholds apply to the specified text/UI role, not every adjacent categorical swatch. CMYK values in this lesson are a teaching approximation; use an output profile and printer proof for production.

Documentation: https://colorspacious.readthedocs.io/en/latest/tutorial.html#simulating-colorblindness
